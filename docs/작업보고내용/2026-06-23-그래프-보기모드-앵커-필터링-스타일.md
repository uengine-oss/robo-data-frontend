# 그래프 화면 기능 — 왜 이렇게 만들었나 (2026-06-23)

코드 그래프 화면의 핵심 기능들을 **왜 필요한지·어떻게 동작하는지** 누구나 이해할 수 있게 정리한 문서입니다. (기술 세부가 아니라 "이유와 동작" 중심)

---

## 1. 보기모드 4가지 — 같은 그래프, 4가지 관점

분석이 끝나면 수백~수천 개의 노드(함수·테이블·구문)와 관계선이 한 화면에 쏟아집니다. 그대로 보면 "털뭉치"라 아무것도 안 보입니다. 그래서 **같은 데이터를 목적에 따라 4가지 방식으로 묶어** 보여줍니다.

| 보기모드 | 무엇을 보여주나 | 언제 쓰나 |
|---|---|---|
| 🔗 **모듈간 상호작용** | 모듈(파일/패키지)끼리 누가 누구를 호출하고, 어떤 테이블을 읽고/쓰는지 | "이 시스템이 크게 어떻게 얽혀 있나" 전체 그림 |
| 🧩 **협력 군집** | 함께 일하는(서로 자주 호출하는) 함수들을 한 덩어리로 묶음 | "어떤 기능 단위(부품)로 나뉘나" |
| 🗺️ **영역(구조)** | 패키지 ⊃ 파일의 폴더 구조 그대로 중첩해서 | "코드가 어떻게 정리돼 있나" |
| 🩺 **건강 보기** | 위험한 루틴(복잡도·순환 등)과 그것이 건드리는 테이블 | "어디가 문제인가, 어디부터 봐야 하나" |

> 핵심: **하나의 그래프를 보기모드만 바꿔** 다른 관점으로 본다. 데이터를 다시 만드는 게 아니라 "묶는 방식"만 바뀝니다.

---

## 2. 앵커노드 — 군집을 만드는 "보이지 않는 닻" (왜 두기로 했나)

보기모드(특히 모듈간·협력군집·영역)에서 노드를 **의미 단위로 동그랗게 묶어** 보여주려면, 노드들을 그 군집 중심으로 모아야 합니다. 그런데 그게 생각보다 어려웠습니다.

**막혔던 길**:
1. **그래프 물리엔진(NVL)으로 묶기** → 실패. 테이블을 여러 함수가 읽고/쓰는 관계선이 **모든 노드를 한 덩어리로 뭉치게** 만들어서, 세부 조정이 안 됐습니다(엔진 내부가 고정돼 있어 손댈 수 없음).
2. **좌표를 직접 계산해 고정 배치** → 사용자가 "딱딱하다/부자연스럽다"고 거부. 그래프 특유의 **출렁이는 유연함**이 사라졌습니다.

**그래서 채택한 방법 = 앵커노드**:
- 군집마다 **눈에 안 보이는 중심점(앵커)**을 하나 두고, 멤버 노드들을 그 앵커에 **옅은 줄로 매답니다**.
- 진짜 관계선(읽기/쓰기 등)은 물리엔진에 안 넣고 그림으로만 따로 그립니다 → 그래서 안 뭉칩니다.

```
   풍선(멤버 노드)을 추(앵커)에 실로 매단 것

        ●    ●                ●    ●
         \\  /                  \\  /
          ⚓앵커A   ←밀어냄→     ⚓앵커B
         /  \\                  /  \\
        ●    ●                ●    ●

   · 앵커가 멤버를 끌어당김 → 동그란 군집
   · 앵커끼리 밀어냄 → 군집끼리 분리
   · 끌면 다시 출렁(자연스러움 유지)
```

**효과**: 유연한 움직임을 살리면서 군집이 저절로 형성·분리되고, 군집 이름표도 앵커 위치에 붙습니다. 한마디로 — **실제 관계선으로는 못 만드는 군집을, "가짜 중심(앵커)"으로 끌어모아** 만드는 장치입니다.

## 3. 필터링 — 보고 싶은 것만 골라 보기 (이번에 추가)

그래프가 복잡할 때 **원하는 종류만 골라** 보는 기능입니다. 노드 상세 패널의 칩(라벨/관계 목록)을 클릭하면 됩니다.

**이렇게 동작합니다**:
- **노드 라벨 여러 개 선택** → 고른 라벨의 노드만 보입니다. 예: `SELECT`와 `TABLE`을 둘 다 누르면 그 두 종류만(다른 건 숨김). 다시 누르면 해제됩니다. 아무것도 안 고르면 전체.
- **관계 타입 여러 개 선택** → 고른 관계선만 보입니다. 예: `READS`·`WRITES`만.
- **노드 + 관계 동시** → 고른 노드들 사이의 고른 관계만(교집합).

> 핵심: **"여러 개 선택 가능 + 선택된 것만 보기"**(누르면 추가/해제되는 토글). 한 번에 한 종류만 보던 이전과 달리, 여러 종류를 함께 볼 수 있습니다.

---

## 4. 색상·선두께 지정

노드 라벨·관계 타입의 **칩을 우클릭**하면 스타일 패널이 열립니다.
- **색상**: 팔레트에서 고르거나 직접 지정. 고른 색이 패널 상단과 그래프에 바로 반영됩니다.
- **두께(관계)/크기(노드)**: 옵션마다 **실제 두께·크기가 다르게** 표시돼, 보고 고를 수 있습니다.

지정한 스타일은 저장되어 다음에 다시 열어도 유지됩니다.
