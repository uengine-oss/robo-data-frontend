# Quickstart & 자가검증: 그래프 탭 의미 기반 코드 검색

## 사전 조건

- 풀스택 기동: Neo4j(7687) · analyzer(5502, **검색 API 배포본**) · catalog(5503) · gateway(9000). (레시피 = memory manual §3)
- 프론트 dev: `cd project/robo-data-frontend && npm run dev` (vite 3000, `/api/gateway`→9000 프록시).
- 그래프 존재: 분석된 그래프(예: 쇼핑몰 neo4j DB)가 로드돼 Overview 패널을 열 수 있는 상태.
- 백엔드 미배포 구간 검증: `/search/semantic` 미구현이면 error/HTTP 경로만 검증 가능(진행·결과 렌더는 스트림 스텁으로 대체 검증).

## 실행 시나리오 (Playwright 헤드리스, 스크린샷 직접 Read)

### S1. 검색 → 진행 → 뭉치 → 캔버스 (US1·US2)
1. 그래프 탭 열기 → 우측 `‹`로 Overview 패널 열기.
2. 검색칸에 업무 말 입력(예: "주문을 취소하면 결제와 재고가 어떻게 원복되는가").
3. 이름 결과 아래 "의미로 더 찾기 · 약 40초" 버튼 확인 → 클릭.
4. **기대**: 그 자리에 단계 label·경과초·취소가 뜬다. 상단 툴바에 "의미검색 중 · N초" 배지.
5. 결과 수신 후 **기대**: 뭉치 목록(title·%·소속노드). 뭉치 클릭 → 노드들이 캔버스에 추가되고 **검색칸·결과 목록 유지**(패널이 Node로 안 바뀜).

### S2. 취소 (US2)
1. 검색 시작 → 진행 중 취소 클릭.
2. **기대**: 진행 표시 사라짐, 이름 결과·검색칸 유지, 이후 결과 튐 없음.

### S3. ⌘K 라우팅 (US3)
1. 그래프 탭에서 ⌘K/Ctrl+K → 상단 검색 포커스 → 질의 입력 → Enter.
2. **기대**: 질의가 Overview 검색으로 전달(왼쪽 트리 필터 아님).

### S4. 실패·빈·임베딩없음 (US4)
1. 임베딩 없는 그래프에서 검색 → **기대**: 서버 사유("이 그래프에는 검색 임베딩이 없습니다") 그 자리 표시.
2. 결과 0건 질의 → **기대**: "못 찾음 + 업무 용어로·자세히" 안내.
3. 빈 검색칸 → **기대**: 짧은 한 줄 안내만(예시 칩·ⓘ 없음).

### S5. 회귀 (기존 무변경)
1. 왼쪽 Navigator 트리 검색 → 여전히 목록 좁히기 동작(placeholder만 "목록에서 좁히기").
2. 캔버스 노드 클릭 → 노드 상세(Node 뷰) 정상.
3. analyze 실행 → 진행 표시에 "검색 색인 만드는 중"(embed) 정상 노출(무변경).
4. 버튼 안 누르면 `/search/semantic` 요청 0(네트워크 탭 확인 — SC-005).
