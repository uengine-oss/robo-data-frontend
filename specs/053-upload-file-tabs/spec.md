# Feature Specification: 업로드 파일 탭과 뷰어 전환

**Created**: 2026-07-14
**Status**: Implementing

## Problem

업로드 후 파일 트리에서 여러 파일을 열면 탭의 최소 너비가 우측 뷰어 영역을 밀어낼 수 있고,
새 탭이 가로 overflow 바깥에 생겨도 자동으로 보이지 않는다. 또한 탭 헤더 클릭만 스크롤을
초기화하고 파일 트리 선택은 `activeTabId`를 직접 변경해 이전 파일의 세로·가로 스크롤 위치가
다음 파일에 남는다.

## Requirements

- 파일 탭은 우측 뷰어 폭을 절대 확장하지 않고 단일 행의 가로 스크롤 영역 안에 머문다.
- 파일 트리·탭 헤더·활성 탭 닫기 등 사용자에 의한 파일 전환은 같은 활성화 함수를 사용한다.
- 사용자 파일 전환 시 코드 뷰어의 세로·가로 스크롤은 항상 시작점으로 이동한다.
- 새로 활성화된 탭이 가로 overflow 바깥이면 탭 스트립만 필요한 만큼 이동해 탭을 노출한다.
- 그래프에서 원문 특정 라인으로 이동하는 동작은 해당 라인 중앙 스크롤을 유지한다.
- 긴 경로명은 탭 내부에서 ellipsis로 줄이고 전체 경로는 title로 확인할 수 있다.

## Acceptance

1. 뷰어 폭보다 많은 파일을 열어도 우측 패널과 페이지 레이아웃이 밀리지 않는다.
2. 파일 A의 아래쪽을 본 뒤 트리에서 파일 B를 선택하면 B가 첫 줄에서 열린다.
3. overflow 끝에 새 탭을 열면 활성 탭이 자동으로 보인다.
4. 특정 line source navigation은 첫 줄이 아니라 요청받은 line을 표시한다.
