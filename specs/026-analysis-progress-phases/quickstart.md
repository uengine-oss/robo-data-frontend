# Quickstart: 분석 진행 표시 7단계 — 라이브 자가검증

> 내가(에이전트) 직접 수행하는 검증. 사용자 UI 테스트 0([[principles]] §6).

## 사전
- Neo4j(7687) 기동.
- 풀스택 기동: `pwsh -File robo-architect/scripts/dev-desktop.ps1 -Build` (프론트 변경 반영 위해 **빌드 포함** — 이 변경은 프론트라 `-SkipBuild` 금지).
  - 빌드는 서브모듈 robo-data-frontend를 쓰므로, 루트에서 작업했다면 **서브모듈 sync 후 빌드**해야 화면 반영됨(이중 체크아웃 주의).
- 분석 대상 준비(framework=zapamcom→neo4j DB / dbms=test DB). 재분석은 해당 DB 덮어씀.

## 검증 절차
1. 분석 1회 실행(framework). 진행 패널 "단계" 탭 관찰.
2. **SC-001**: 최상위 항목이 항상 **정확히 7개**(DDL 파싱~후처리)인가? (leaf 17개 평평 나열 아님)
3. **FR-002**: 진행에 따라 각 단계가 대기(○)→진행중(▶)→완료(✓)로 전이하는가?
4. **US2/FR-004/SC-004**: 진행 중 단계 **하나에만** 세부 한 줄(예 "관계 연결 — 함수 호출 분석 중")이 뜨고, 완료/대기 단계엔 세부가 없는가?
5. **SC-002/FR-006**: 화면 문구에 내부어(영문 함수명·`*_step`·"호출 이름 분류" 류) **0건**인가?
6. **SC-005/FR-007**: framework 런에서 테이블 샘플 조회가 skip돼도 "분석 컨텍스트 구성"이 완료로 표시되고 오류 표시 없는가?
7. **SC-003/FR-008**: 분석 완료 시 7단계 모두 완료. (가능하면 dbms 런도 1회 → 동일 7단계.)
8. **회귀**: "그래프 객체"·"콘솔" 탭, 진행바·경과시간·일시정지/재개·드래그·최소화 배지 정상.

## 자가검증 하니스
- Electron은 `app://`라 Playwright 헤드리스 스크린샷 직접 불가 → 데이터 경로(catalog HTTP)는 별개로 확인되고, **진행 패널은 store 파생값** 검증이 핵심: 분석 NDJSON 스트림을 받아 `maxPhaseSeen`/단계 상태가 규칙대로 가는지 콘솔/상태로 확인. 가능하면 dev 브라우저(vite, `localhost`)로 패널만 띄워 스크린샷.

## 통과 기준
위 2~8 전부 충족 + 콘솔 에러 0 + 기존 진행 패널 기능 무회귀.
